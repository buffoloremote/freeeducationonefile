Cheat / modded game versions

Any game can have a cheat version. Drop a modded hacked.html into that game's folder (e.g. games/<Game Name>/hacked.html) and push. A "⚡ Cheat version" toggle then appears automatically in the 🎮 in-game menu for you and anyone you gave the Game hacks perk. The normal game stays the default for everyone else.

Where to get them

Eaglercraft (Minecraft) hacked clients: search GitHub for "eaglercraft hacked client" / EaglerClientArchive. Browser-game mods & trainers: GitHub (search the game name + "mod"/"hacked"), GreasyFork (userscripts), and unblocked-games repos that ship "hacked" folders.
⚠ Vet anything you download — "cheat client" files can hide malware. Only add files you trust, and open them once yourself first.
